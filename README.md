# blog-comments

Comment threads for [blog.lezli01.is-a.dev](https://blog.lezli01.is-a.dev), powered by
[giscus](https://giscus.app). Each post maps to one Discussion in the **Announcements**
category (by URL path), created automatically on the first comment.

- `giscus.json`: only the blog, its Vercel previews and localhost may embed these threads.
- `giscus-theme.css`: the blog's gruvbox theme for the giscus frame, served via jsDelivr at a
  pinned commit. After changing it, update the commit in the blog's `src/consts.ts`.
